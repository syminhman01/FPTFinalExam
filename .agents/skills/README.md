# Skills của dự án

Chỉ thêm skill khi có quy trình lặp lại đáng tái sử dụng.
Ví dụ: kiểm tra bàn giao, thêm endpoint theo quy ước đã ổn định.

Mỗi skill nằm trong thư mục riêng và có SKILL.md với name, description và hướng dẫn.
README này không phải skill và không kích hoạt quy trình nào.
Không cần sao chép toàn bộ AGENTS.md vào skills.
