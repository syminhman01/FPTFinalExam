# Kế hoạch

- Dùng cho tính năng nhiều bước, thay đổi kiến trúc hoặc dữ liệu đáng kể.
- Sao chép PLAN-TEMPLATE.md vào active/ với tên mô tả.
- Cập nhật tiến độ trong quá trình làm; khi nghiệm thu xong, chuyển sang completed/.
- Tác vụ nhỏ không cần tạo file kế hoạch riêng.
- File kế hoạch tồn tại không có nghĩa đã được duyệt; ghi rõ trạng thái và quyết định.
