## Điều kiện
- Runtime và phiên bản: [CẦN ĐIỀN]
- Công cụ quản lý gói và phiên bản: [CẦN ĐIỀN]
- Docker/Compose nếu dùng: [CẦN ĐIỀN]
- Biến môi trường: xem .env.example trong từng phần sau khi chọn công nghệ.

## Lệnh chính thức

| Công việc | Thư mục chạy | Lệnh đã xác minh |
| --- | --- | --- |
| Cài frontend | frontend/ | Chưa thiết lập |
| Chạy frontend | frontend/ | Chưa thiết lập |
| Cài backend | backend/ | Chưa thiết lập |
| Chạy backend | backend/ | Chưa thiết lập |
| Chạy hạ tầng local | infra/ | Chưa thiết lập |
| Lint / kiểm tra kiểu | Theo ứng dụng | Chưa thiết lập |
| Unit / integration / E2E | Theo phạm vi | Chưa thiết lập |
| Build | Theo ứng dụng | Chưa thiết lập |
| Migration | backend/ | Chưa thiết lập |

Thay các mục trên bằng lệnh thực tế đã chạy thành công. Không coi mẫu này là ứng dụng có sẵn test/build.

## Hoàn thành tác vụ
Đạt tiêu chí nghiệm thu; kiểm tra phù hợp thành công; diff đúng phạm vi;
tài liệu liên quan được cập nhật; ghi rõ kiểm tra không chạy được và lý do.
